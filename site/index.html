A few things to know.

Is this a hosted service?

No. Homeport is open-source software you run on your own Mac mini. This website is the public introduction; your workspace stays on your machine, reachable privately through Tailscale.

Does it use my ChatGPT account?

Homeport reuses normal Codex authentication. The original installation was verified with a ChatGPT Pro account, without a separate API key. Your account’s Codex access and usage limits still apply.

What happens when I close my laptop?

Tasks keep running on the Mini while it is awake. tmux preserves the processes through SSH disconnects, and launchd supervises the service. After a reboot, it starts when the macOS user logs in; unattended FileVault unlock is not part of the setup.

What access does Codex have?

This version intentionally gives Codex full filesystem and network access as the signed-in macOS user, with no command-approval prompts. It does not grant root or bypass macOS privacy controls. Use a machine and account where you intend to allow that access.

How early is “early”?

Homeport has been tested on an Apple Silicon Mac mini with Codex CLI 0.160.0. It includes browser-based task submission, file previews, saved conversations, and restart recovery. The app-server interface is experimental. It is a personal workspace, with one worker, rather than a full browser IDE or a multi-user service.
