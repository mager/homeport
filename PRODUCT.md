# Homeport

## Register

product

## Users

Mager starts coding work from a laptop and checks in from a phone. The Mac mini is the persistent home for projects, Codex conversations, and task results. The browser is the everyday entry point; the Codex CLI is optional.

## Product Purpose

Start a task, leave it running, and return from another device to inspect progress, review code, and continue the same conversation. A task-and-chat workspace comes first, with file review, rather than a full browser IDE. The user approved this direction and the Homeport working name on October 4, 2026.

## Brand Personality

Warm, curious, grounded. Talk like a thoughtful human peer. Brief, useful progress updates; clean closures without promotional boilerplate. The product should help the user feel capable and keep control of their work.

## Anti-references

No decorative dashboards, marketing heroes, or fake metrics. No requirement to understand tmux or keep a terminal attached to use the product. No promise that a submission succeeded when its outcome is uncertain.

## Design Principles

- Work stays on the Mini; the user can come and go.
- Conversations and real task state are the primary interface.
- Show progress and files with enough context to make the next decision.
- Preserve continuity across devices, reloads, and disconnects.
- Codex does the coding. Python and Pydantic keep the surrounding workflow reliable.

## Accessibility & Inclusion

Keyboard-friendly forms, visible focus, labeled status, readable contrast, and responsive layouts for phone and laptop. Respect reduced motion and avoid motion that doesn't convey state. These standard defaults implement the user's delegated design direction.

## Visual Direction

The owner explicitly requested a black, terminal-like interface after trying the initial light sage palette. Use true black, neutral charcoal panels, monospace typography, fine borders, compact controls, and restrained cyan for action and focus. No green garden-like palette. Archive sessions without deleting history; restoration should be easy.

Use regular-weight monospace text, including session titles. Sidebar rows show labeled semantic status colors, project, task count, and last activity. Session actions are available through right-click, keyboard, and a visible overflow button for touch.
